## 数据含义

每例保留原始 RGB、毫米深度、掩膜、相机内参、完整/目标点云、NMS 后与最终候选、诊断 JSON 和原始可视化，未缩放图像或改变点云。点云与候选都在该帧 ZED 光学坐标系，单位米；深度 PNG 为毫米。`grasp_before_filter.npy` 为 NMS 后、任务筛选前的 Nx17 候选；after 为 READY 候选（对称朝向独立保存）。索引0是实际执行的候选，第三例未执行。操作者结果另存于各目录的 `operator_outcome.json`。

[配置快照](config_snapshot)保留 Home、真实夹爪几何与运动/力参数；未包含 SAM2/FFS 权重。两轮默认命令力为30 N，驱动报告约29.3 N，是命令寄存器换算值而非独立测力。第一轮两个采集 JSON 缺少后来新增的相机外参/方案字段，不用当前数据倒填历史变换。

## CAD 辅助的实际结论

操作者确认实体与 [Cat 06 模型](../../../models/obj_06.ply)同模同原尺寸，尺寸与 [LINEMOD 信息](../../../models/models_info.yml)第6类一致（67.0107 × 127.6330 × 117.4566 mm）。模型读入几何分析时按0.001转米。`cad_quickcheck/` 是操作者提供压缩包中的原始工具与说明，归档时未修改；不连接硬件。

第一轮每帧仅做一次离线配准（seed=17、CAD 30000点、voxel=3.5 mm），结果在各自 `cad_cat_probe/`：

| 指标 | 第1次 | 第2次 |
| --- | --- | --- |
| 观测点到 CAD 覆盖率（7 mm 容差） | 69.4% | 96.5% |
| 最近邻 RMSE | 9.29 mm | 5.39 mm |
| 同一组 READY 候选的实体检查：原观测 → 观测+CAD | 16 → 14 | 2 → 2 |

[对照图](cat_cad_comparison.png)中黄色为输入掩膜、青色为 CAD 投影、紫色为选中候选的开口示意（不是完整夹爪）。两次实际执行的候选加 CAD 后仍通过实体检查，尚未证明仅补 CAD 碰撞即可改善抓点。第1次配准较差，不能据此自动修正位姿；第2次无真实位姿标注，表面覆盖好也不等于抓取成功。中心线射线诊断不是完整指垫接触/力闭合判定，不能当成抓取成功指标。

工具会居中 CAD；`cad_to_observation.txt` 对应居中模型，补充保存的 `cad_original_m_to_camera_m.txt` 已恢复原模型原点，但输入仍须先从毫米转米。离线对照没有重跑 GraspNet、没有重放机械臂 IK、没有证明稳定实物成功率提高。
